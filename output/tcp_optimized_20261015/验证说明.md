# TCP 标定仿真优化与验证

日期：2026-10-15。
远程工作区：`/home/dky666/zhul/codex_guohua_ws`。
ROS 2 Jazzy、Gazebo Harmonic、MoveIt 2。

## 实现改动

- 采样改为等待控制器、关节状态和工具 TF 就绪，取消默认固定 40 秒延迟；采样节点加载已有的速度及加速度限制。
- 默认隔离到 ROS 域 67、Gazebo 分区 `tcp_calibration_sim`，未关闭或修改正在运行的域 168 示教程序。
- 工具尺寸和方向从实际工具固定 TF 读取，避免 C++ 与模型重复维护几何真值。
- 换姿态采用固定针尖位置的笛卡尔旋转路径，进行完整路径比例、碰撞、时间参数化和关节跳变检查。计划针尖偏差超过 0.75 mm 不执行，运行中观测偏差超过 2 mm 停止。
- 工装针杆、底座和支柱增加 Gazebo 碰撞几何，并同步为 MoveIt 障碍物；工具针杆和锥尖均有碰撞几何。
- 工装确认匹配当前请求时间戳，同场景重复标定及工装节点恢复会更新工装与碰撞场景；工装失败不再复用旧确认。
- 增加独立精度验收阈值，验收未通过不输出成功；工装创建后自动聚焦 Gazebo 相机。

- MoveIt 工装包含四个碰撞几何体；当前右臂姿态的碰撞有效性检查通过。
- 六项数学测试及三项工装确认/重试回归测试全部通过；Python 语法和本次 TCP 包的 Git 空白检查通过。
