# 首箱搬运：仅腕部六维力估测箱底支撑（2026-10-16）

测试通过。复用正在运行的九箱 Gazebo 场景，仅操作 `pallet_box_r0_c0`。
当前实例通过一次性 ECM 插件删除九个 `tote_bottom_contact` 子传感器；
最终 ECS 实体检查确认传感器 ID 均不存在。源世界及可复现场景也已移除箱体传感器。
大箱和小箱的碰撞几何保留，腕部六维力传感器保留。

## 估计与控制

`N_est = (15.0 + 0.56) * 9.81 + F_left_world_z + F_right_world_z`。
两腕力先经 TF 和底盘姿态旋转到世界坐标系，使用有符号竖直合力，不能相加力模长。
每侧工具质量 0.28 kg 由当前 URDF 下游惯性质量求和确定。估计器独立于导纳去皮，
没有对持箱负载去皮。检查六轴有限性、时间同步、TF/底盘姿态新鲜度，2 Hz 低通滤波。
只估计法向支撑 `force.z`，其他 Wrench 分量不表示已辨识接触力矩。

首箱 50 mm 仅双臂导纳段通过：实际 49.458 mm，
最大横向偏差 0.298 mm，
停止速度 1.666 mm/s。
悬空段估计均值 -0.066 N。

随后用 MTC 执行底盘导航、插入和收臂；近底板阶段用腕部估计闭环竖直导纳微步落座，
`D*v = 147.15 - N_est`，单步上限 0.25 mm。
估计到约 129 N 支撑时先小幅卸掉夹紧预载，随后测得约 147.1 N、箱心 0.636 m、倾斜 0°，
支撑与几何检查稳定通过才放爪。

记录中夹爪首次低于 0.04 m 时，估计支撑为 **147.15 N**，
箱心为 `[0.9801565178292014, -1.5499970748362046, 0.6359997737937515]`。物理放置位置检查和双臂收回均通过。
其余八箱最大位移 0.000575 mm。

## 适用范围

这是低速准静态估计；动态加速度会产生惯性误差，悬空过渡段出现短暂负值未做截断。
腕力只能给出总竖直环境支撑，结合底板几何及碰撞余量推断箱底反力，不能独立区分侧壁摩擦。
147.15 N 与模型箱重一致是静态一致性检查，并非独立地面力传感器精度标定。
本次为 Gazebo 仿真验证。
