## 2. 200 mm间距的定义

**升降台实体外轮廓边沿与大桌台面边沿之间，俯视水平投影的最短净距离至少200 mm。**

- 测量对象为升降台可见几何外轮廓，不以机器人中心、底盘中心或立柱中心作为测量起点。
- 运行配置：`column_table_clearance = 0.200 m`。
- 另加余量：`column_table_margin = 0.004 m`。
- 当前程序实际检查门槛：**204 mm**。
- 弯腰躯干、手臂和夹具同时接受各自的三维碰撞检查。

## 5. 搬运流程与运动参数

| 项目 | 当前设定 |
|---|---|
| 箱子索引顺序 | `0, 1, 2, 6, 7, 8, 5, 4, 3` |
| 索引定义 | `index = row × 3 + col`，行列从0开始 |
| 前、后排流程 | 先侧拉，再双手抓取、抬升、运输、落箱、松爪、退手 |
| 中排流程 | 先从后侧推出，再双手抓取搬运 |
| 前、后排侧拉距离 | 120 mm |
| 中排推出距离 | 324 mm；另设20 mm过行程参数 |
| 搬运／放置准备箱心高度 | 名义离地940 mm；落箱时继续下降至底部支撑 |
| 放置接近净空参数 | 280 mm |
| 工具与本体净空参数 | 3 mm |
| 载箱底盘最大线速度 | 0.06 m/s |
| 载箱底盘最大角速度 | 0.09 rad/s |
| 载箱底盘线加速度 | 0.03 m/s² |
| 载箱底盘角加速度 | 0.04 rad/s² |
| 空载底盘最大线／角速度 | 0.20 m/s、0.30 rad/s |
| 手臂速度／加速度缩放 | 0.12、0.08 |
| 空载手臂速度／加速度缩放 | 0.20、0.12 |
| 抓取闭爪速度上限 | 0.5 mm/s（全流程导纳模式） |

大箱每次接收一个小箱。前八箱完成实际放置、松爪、退手、机械臂回位及空载回程后，清空接收位再搬下一箱；最后一箱无需空载回程。当前流程不在大箱中累计堆放九箱。

## 6. 六维力传感与导纳控制

| 项目 | 当前配置 |
|---|---|
| 传感器位置 | 左、右腕部六维力／力矩传感器 |
| 测量量 | 每侧Fx、Fy、Fz、Tx、Ty、Tz及合力／合力矩大小 |
| 大箱底部传感器 | 不使用；底部支撑反作用力由腕部测量估算 |
| 导纳平移修正上限 | 每轴0.5 mm |
| 导纳转动修正上限 | 每轴0.0005 rad（约0.0286°） |
| 采样保护阈值 | 每侧合力450 N、合力矩100 N·m |
| 落箱释放条件 | 先确认箱底获得支撑，再卸载、松爪 |
| 运行方式 | 无Gazebo GUI |
| 录像数据要求 | 弯腰角度、升降关节高度、左右腕部力大小 |

说明：上述阈值是控制器采样检查参数。历史原始力矩记录仍出现过短时超过100 N·m的峰值；不能据此宣称全部瞬态力矩均已受控。当前全流程导纳采用低速分段反馈，不应描述为100 Hz实时闭环。
