# 九箱单场景连续录制（2026-10-13）

## 用户新要求

按第一排 → 第三排 → 中间排，从头到尾一次性录完；进一步优化轨迹与速度，夹爪不能碰机器人本体。视频不要黑色说明画面。此前含检查点拼接的视频不作为本次最终交付。

## 当前实现

- 新入口 `scripts/run_pallet_nine_continuous.py`，仅支持从九箱初始场景开始，不支持续录、重建剩余场景或拼接。顺序索引 `[0,1,2,6,7,8,5,4,3]`。
- 单个 Gazebo/MoveIt 场景与单个录制器贯穿全部九箱；初始九箱均为完整 15 kg 物理箱。第一、三排先侧拉 120 mm，中间排采用此前对面推送和正面双臂取箱流程。
- 所有未搬箱体保留并加入规划。监督器持续观察未处理箱体，箱高低于 0.20 m、倾斜超过 5°或平移超过 40 mm则中止本轮，不续接为成功片段。
- 沿用接料箱每轮清场流程：仅在放置、收臂和空车返回均验证后移除已放置箱。源箱和机器人从不重建/复位。失败必须从九箱起点重录。
- 接收端场景清箱仍是既有仿真操作，不代表真实自动卸料机构。

## 轨迹与速度

- 空车 0.20 m/s、0.30 rad/s；负载 0.12 m/s、0.18 rad/s；底盘加速度 0.08 m/s²、0.10 rad/s²。
- 空载协调接近机械臂比例 0.20/0.12，负载比例 0.12/0.08；侧推 TCP 实际速度仍受 0.015 m/s 限制，落底仍逐步低速执行。
- 连续轨迹合并、压缩冗余点、重定时后重新检查；保持接触/吸附规划场景变化的分段边界。
- 各箱直接空载返回下一实际操作站，排间经北侧绕行；后侧从外部直线靠站，避免为毫米级残差多次转圈。精确靠站参数已通过 launch 正确传递。
- 第一箱也使用协调腰臂接近，取消本轮的独立盲弯腰。中间排后侧推送后缩短北侧回正面路线。

## 夹爪与本体检查

- 还原夹爪与底盘、腰、头、相机、车轮及非装配相邻手臂的碰撞检查，覆盖左右两套夹爪与对侧夹爪。
- IK 候选、原始完整轨迹、重定时轨迹分别检查。独立硬检查矩阵不继承任务阶段中的宽泛碰撞豁免。每次轨迹采样最大间距 0.005 rad / 0.5 mm，要求 3 mm间隙。
- 执行中每 200 ms按实测关节再次检查，发现间隙不合格则取消动作并停底盘。危险候选只重规划，不重放执行失败动作。
- 自身腕部装配固定相邻几何仍按装配关系排除；其他历史非夹爪碰撞豁免仍存在。本任务不能据此宣称整个机器人所有自碰撞模型都重新验证。

## 录像

`--clean-video` 直接保存 960×540 摄像机像素，无黑色字幕栏、标题卡或流程描述。一次生成原速 WebM与均匀抽帧8倍速 WebM，最终只转码，不进行视频拼接。阶段、箱序、时间、关节、接触与位置证据保存在单独 JSONL日志。

录制器退出改为显式停 ROS执行器和取消Gazebo订阅，处理之前退出清理时 native segfault 的风险。
